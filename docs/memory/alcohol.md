
```Дача```

- водка — очистка воды, замачивание зерна -> солод (в процессе хим реакций крахмал расщепляется до сахаров), добавление дрожжей, ректификация;
- ром — из тростника или **мелассы** (выдавливается сок, выпаривается до концентрата, который центрифугируется на кристаллы сахара и как раз мелассу), дистилляция после добавления дрожжей;
- виски — дистиллят, отстаивание в бочках;
- херес — креплёное вино из винограда **паломино**, производится на ЮЗ Андалусии
- бренди — дистиллят:
    - коньяк (Шаранта);
    - арманьяк (Гасконь);
    - хересный бренди;
    - дивин (Молдавия);
    - писко (Перу и Чили) — из винограда **муската**;
    - плиска (Болгария);
    - Метакса (Греция) — уникальный, + травы и лепестки роз;
    - арбун (Армения);
    - виньяк (Югославия и Сербия);
    - граппа (Италия, из остатков винограда);
    - чача (Грузия, из остатков винограда);
    - цИпуро (Греция, из остатков винограда);
    - ракЫ — турецкий бренди с добавлением экстракта аниса;
    - кальвадос(Нижняя Нормандия) — яблочный, грушевый бренди, перегонка сидра

- мескаль;
- текила — дистиллят, только в Мексике, из агавы (её сердцевины — пиньи): томление в автоклавах, измельчение и прессование для получения сладкого сока (агуамиель), добавление дрожжей, брожжение и дистилляция (2х), разбавление;
- Б-52 — многослойный шот (кофейный, сливочный, апельсиновый ликёры), поджигают перед подачей;
- байцзю (шаоцзю) — китайская водка;
- мятный джулеп — бурбон, сахарный сироп, лёд, листья мяты

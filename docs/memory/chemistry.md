### **Глинка**

```ИТМО```

- технический, чистый, чистый для анализа, химически чистый, особо чистый;
- глёт (оксид свинца), плюмбат свинца (сурик);
- белый и красный фосфор;
- Гей-Люссак — закон объемных отношений;
- закон Авогадро;
- правило Дюлонга и Пти;
- атомные модели Томсона, Резерфорда и Бора;
- спектры излучения твердых/жидкостей и раскаленных газов;
- фотоэлектрический эффект;
- эффект Зеемана;
- электронный (нейтрон -> протон, испускает электрон и антинейтрино) и позитронный (протон -> нейтрон, испускает позитрон и нейтрино) бета-распад;
- дипольный момент (Дб = Кл × м);
- диамагнетики (против направления внешнего магнитного поля), ферромагнетики (сильно намагничиваются, собственное поле), парамагнетики (слабо по направлению внешнего магнитного поля);
- неспаренные электроны - собственное магнитное поле (из-за спина);
- спаренные электроны - нет поля;
- коллодий (коллоксилин - динитроцеллюлоза - в этаноле + диэтиловый эфир);
- сосуд Дьюара;
- эффект Мпембы;
- аконит;
- атропин;
- скополамин;
- клавулановая кислота;
- дицианин (сенсибилизатор к красному);
- P10 (белок);
- десфлуран;
- обогащённый уран (из 238 получение 235);
- получение волокна из полимеров (сухой и влажный методы);
- аммиачно-медный шёлк, купро (искусственное волокно, получаемое растворением целлюлозы в реактиве Швейцера, замещение аминогрупп);
- вискозное волокно (искуственное, получение вискозы (ксантогената) из древесины взаимодействием с сероуглеродом, экструзия через фильеру);
- полиакрилнитриловое волокно (нитрон, орлон);
- химическая обработка волос (разрушение дисульфидных мостиков тиогликолевой кислотой);
- нитрид титана (позолота куполов);
- солевой эффект (добавление сильного электролита без ионов нерастворимой соли увеличивает растворимость соли);
- определение азота по Кьельдалю (окисление с серной кислотой при нагревании до сульфата аммония -> получение раствора аммиака -> перегонка -> поглощение кислотами -> титрование);
- суть работы АЭС (бомбардировка ядер урана-235 нейтронами -> нагревание воды под высоким давлением -> тепло передаётся воде в другом контуре -> пар двигает лопатки турбины -> вращение в электрический ток);
- бактерии (клеточные) и вирусы (днк/рнк в белке);
- оплодотворение яйцеклетки (в фаллопиевых трубах -> зигота);
- близнецы однояйцевые (одна зигота -> 2 эмбриона) и разнояйцевые (2 разные яйцеклетки оплодотворены разными сперматозоидами);
- хлорид цинка — антисептик (пропитывается древесина от гниения), хлорид бария — пестицид (инсектицид).
